# Wissensbasis – Kletterwelt Sauerland

## Wie funktioniert die Wissensbasis?

Alle `.md`-Dateien in diesem Ordner werden automatisch vom Bot gelesen und als Grundlage für seine Antworten verwendet.

**Der Bot antwortet NUR auf Basis dieser Dateien.** Er erfindet keine Informationen.

## Dateien bearbeiten

1. Öffne eine `.md`-Datei mit einem Texteditor (z.B. Notepad, VS Code)
2. Bearbeite den Inhalt
3. Speichere die Datei
4. Ruf `/api/knowledge/reload` auf (mit Admin-Token) oder starte den Server neu

## Neue Kategorie hinzufügen

Erstelle einfach eine neue Datei, z.B. `veranstaltungen.md`, und fülle sie mit Inhalt.

## Tipps für gute Einträge

- Klare, kurze Sätze schreiben
- Zahlen und Preise immer aktuell halten
- Häufige Fragen direkt beantworten (FAQ-Stil)
